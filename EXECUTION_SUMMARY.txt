🎯 CUSTOMIZATION QUICK TIPS

Update Brand Content:
1. Edit src/constants/data.js
2. Change NAV_LINKS, INITIATIVES, QUOTES, HERO_STATS
3. Changes appear instantly in dev server

Replace Images:
1. Find Unsplash URLs in components
2. Replace with your own image URLs
3. Ensure images are optimized

Modify Colors:
1. Update src/constants/theme.js
2. Or edit tailwind.config.js
3. Rebuild if needed

Adjust Animations:
1. Edit component variant durations
2. Change transition: { duration: 0.75 }
3. Or modify whileHover scales
